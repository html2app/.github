# html2app

**Turn your HTML5 game or web app into a native Android app.**

[Website](https://html2app.dev) · [Docs](https://html2app.dev/docs/index.html) · [JS Bridge API](https://html2app.dev/js-bridge/index.html) · [Discussions](https://github.com/html2app/discussions/discussions)

</div>

---

html2app wraps HTML5 projects (Phaser, Three.js, Pixi.js, React and more) into signed Android builds, with a JavaScript bridge for native features such as vibration, sharing, camera and ads.
